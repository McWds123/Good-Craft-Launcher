# Good Craft Launcher for PC

一个Minecraft启动器，使用 C# 和 WPF 编写。

> 本项目与 Mojang、Microsoft 无关联。

---

## 目前状态

早期开发中，基础功能还在慢慢搭建。

---

## 功能（计划中）

- 启动游戏
- 下载游戏
- 管理游戏版本
- 下载游戏模组
- 管理游戏模组

---

## 技术栈

- **语言**：C#
- **界面**：WPF
- **框架**：.NET

---
